# Фактура — студия объёмных картин (КР №2, Bootstrap)

Учебный многостраничный сайт творческой студии «Фактура»: мастер-классы по текстурной живописи, запись онлайн, праздники в мастерской.

**Сайт:** https://amosovakate.github.io/kr2-bootstrap-shop/

**Репозиторий:** https://github.com/amosovakate/kr2-bootstrap-shop

## Страницы

| Страница | Файл | Что на ней |
|---|---|---|
| Главная | `index.html` | Первый экран, популярные мастер-классы, техники, галерея, преподаватели, расписание, отзывы, карта «Как нас найти» |
| Мастер-классы | `catalog.html` | Каталог карточек с фильтрами по уровню и цене, быстрая заявка |
| День рождения в мастерской | `product.html` | Описание услуги, вкладки, тарифы, характеристики, частые вопросы, окно «Бронь праздника» |
| Запись | `order.html` | Форма записи на мастер-класс с итоговой карточкой |

## Подключение Bootstrap

Bootstrap 5.3.3 подключён через CDN на всех страницах:
- CSS в `<head>` до `css/custom.css`, чтобы свои стили переопределяли библиотечные;
- JS (`bootstrap.bundle.min.js`) перед закрывающим `</body>`.

## Сетка (grid)

Используются `container`, `row`, `col-*` с адаптивными брейкпоинтами и отступами `g-*`:
- карточки мастер-классов: `col-6 col-md-6 col-lg-4 col-xl-3`;
- техники: `row-cols-2 row-cols-md-3 row-cols-lg-5`;
- каталог: боковая панель фильтров `col-lg-3` + список `col-lg-9`;
- страница праздника: фото и текст в две колонки, тарифы `col-lg-4`.

## Компоненты Bootstrap

| Компонент | Где используется |
|---|---|
| Navbar + toggler (collapse) | Шапка на всех страницах, на телефоне сворачивается в бургер |
| Card | Карточки мастер-классов, тарифы, контакты, характеристики |
| Badge | Метки «Хит», «К Новому году», «Новая услуга» |
| Buttons | Кнопки действий на всех страницах |
| Alert | Подсказки в каталоге и на странице праздника, сообщение об успехе |
| Modal | Быстрая заявка в каталоге, «Бронь праздника» на `product.html` |
| Nav pills (tabs) | Вкладки «Что входит / Программа / Условия» на `product.html` |
| Accordion | Блок «Частые вопросы» на `product.html` |
| Table | Расписание занятий, характеристики праздника (`table-responsive`) |
| Breadcrumb | Навигационная цепочка на `product.html` |
| Forms | `form-control`, `form-select`, `form-check`, проверка полей (`invalid-feedback`) |

## Свои доработки (custom.css и JS)

- Тема в духе студии: цвета, шрифты (Cormorant Garamond + Manrope) и скругления заданы CSS-переменными.
- Адаптивная вёрстка: на телефоне карточки по две в ряд, техники, преподаватели и тарифы листаются свайпом, расписание превращается в карточки.
- Каталог: фильтрация по уровню и цене на JS.
- Формы: проверка телефона по маске, счётчик символов в комментарии, счётчик гостей.
- Страница `product.html`: бронь праздника с выбором тарифа, количества гостей и даты.
- Карта Яндекс с адресом студии в блоке «Как нас найти».
- Кнопка «Наверх», слайдер отзывов, окна галереи и преподавателей.

## Запуск

Откройте `index.html` в браузере или запустите Live Server в VS Code. Сборка не нужна.
