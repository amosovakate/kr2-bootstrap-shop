# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

«Фактура» — учебный сайт творческой студии объёмных картин. Пользователи могут посмотреть каталог мастер-классов, изучить техники и материалы, галерею работ и преподавателей, а также записаться на занятие. Проект разработан с использованием Bootstrap 5.

## Практическая работа 9

Главная страница переведена на Bootstrap-сетку.

Реализовано:

- подключение Bootstrap CSS и JS Bundle через CDN;
- подключение `css/custom.css` после Bootstrap;
- шапка страницы и навигация;
- hero-блок на сетке (`container`, `row`, `col-12 col-lg-8` + `col-12 col-lg-4`);
- блок преимуществ (`row g-4`, `col-12 col-md-4`);
- сетка популярных мастер-классов (`row g-4`, `col-12 col-md-6 col-lg-4 col-xl-3`);
- сетка преподавателей (`row g-4`, `col-12 col-md-4`);
- подвал страницы;
- utility-классы Bootstrap: `my-5`, `mb-4`, `p-4`, `h-100`, `g-4`, `text-center`, `shadow-sm`, `rounded`, `border`.

## Практическая работа 10

Тема: «Страница на Bootstrap: компоненты».

Выполнено:

- единая Bootstrap-навигация `navbar` с мобильным меню (`navbar-toggler`) и выпадающим списком (`dropdown`) на всех страницах;
- каталог `catalog.html`: карточки мастер-классов на компоненте `card`, метки `badge`, кнопки `btn`, сообщение `alert`;
- страница `product.html`: подробное описание мастер-класса (данные подставляются по параметру `?mk=`), хлебные крошки `breadcrumb`, таблица характеристик `table`, `alert`;
- модальное окно `modal` с быстрой заявкой (открывается кнопкой «Заказать» через `data-bs-toggle="modal"`);
- форма записи `order.html` на классах `form-control`, `form-select`, `input-group`, `form-check`, сетка полей `row g-3`;
- дополнительный компонент `accordion` (частые вопросы на странице товара);
- фирменные цвета заданы через CSS-переменные компонентов Bootstrap (`--bs-btn-*`, `--bs-accordion-*` и др.) в `css/custom.css`.

Использованные компоненты: `navbar`, `dropdown`, `card`, `btn`, `badge`, `alert`, `modal`, `breadcrumb`, `table`, `accordion`, `form-control`, `form-select`, `input-group`, `form-check`.
